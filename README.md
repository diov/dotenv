# dotenv

Personal macOS environment, installed by symlinking files from this repo into `$HOME`.

## Scope

- Apple Silicon macOS only (`/opt/homebrew` is assumed).
- Prerequisites on a new machine:
  - [Homebrew](https://brew.sh) installed manually (its installer needs sudo).
  - A GitHub SSH key (`git/gitconfig` rewrites `https://github.com/diov/` to SSH).

## Install

```bash
./install.sh            # everything, in order: brew → zsh → git → ghostty → mise → rust → agent
./<module>/install.sh   # a single module
```

Scripts can be run from any directory, and running them again is safe:

- A target that already links to this repo is skipped.
- A target that is a symlink elsewhere (or dangling) is replaced.
- A regular file or directory is moved to `<target>.backup` first. If that backup already exists, the script stops instead of overwriting it.

Nothing is upgraded: `brew bundle` runs with `--no-upgrade`, `mise install` only adds missing tools, rustup is not updated.

## Modules

| Module | What it manages |
|---|---|
| `brew/` | A hand-written whitelist of Homebrew packages |
| `zsh/` | zsh config, plugins and theme |
| `git/` | Global git config and ignore file |
| `ghostty/` | Ghostty terminal config |
| `mise/` | Language runtimes (Go, Node, Python, Java, …) and global CLI tools |
| `rust/` | rustup and the stable toolchain |
| `agent/` | User-level rules and settings for Claude Code and Codex |
| `handbrake/` | A HandBrake preset. No script: import it in HandBrake via *Presets → Import* |

## Who manages what

| Thing | Manager |
|---|---|
| Go, Node, Python, Java, Bun, Deno, pnpm, uv | mise |
| Global CLI tools (`codex`, `pyright`, `mmdc`, `baw`, `ruff`, `git-filter-repo`) | mise (`npm:` / `pypi:` backends) |
| Python used by uv | mise, through `UV_PYTHON` |
| Rust | rustup |
| `coreutils ffmpeg gh imagemagick rtk zsh` | Homebrew |
| `/usr/bin/python3` | macOS (Xcode CLT), left untouched |

Tools with their own official installer (mise, rustup) are not installed through Homebrew.

## Not tracked

- `~/.codex/config.toml`: contains secrets and machine-specific trust settings.
- `~/.codex/RTK.md`, `~/.codex/hooks.json`: generated by `rtk init -g --codex` (run by `agent/install.sh`).
- `~/.zsh/` plugins, cache and history: cloned or downloaded by `zsh/install.sh`.

Install these manually on a new machine with their official installers: `claude`, `agy` (Antigravity), `duckdb`, Ghostty.

## Known issues

- This repo is public. Never put API keys in `agent/claude-settings.json` (for example under `env`).
- `agent/AGENTS.md` contains an absolute `@/Users/<name>/.codex/RTK.md` line owned by rtk. On a machine with a different user name, rtk appends its own line.
- Claude Code plugins listed in `agent/claude-settings.json` may need `/plugin install` on a new machine (unverified).
